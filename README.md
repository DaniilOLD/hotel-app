# Гостиница 

Программа для учёта и распределения гостей по номерам гостиницы с учётом пожеланий.

## Технологии

- **C++17**
- **Qt 6** (Widgets)
- **ООП** — иерархия классов
- **Паттерны:** Singleton, Facade, Factory Method, Strategy
- **Многозначные зависимости:** Room→Features, Guest→Preferences

## Функционал

- **Гости:** добавление, удаление, просмотр
- **Номера:** просмотр (5 Эконом, 3 Стандарт, 1 Люкс)
- **Подбор номера** под пожелания гостя
- **Бронирование:** создание, удаление, выселение
- **Отчёты:** свободные номера, проживающие гости, статистика
- **Автосохранение** в файл

## Запуск

1. Открыть `untitled.pro` в Qt Creator
2. Собрать (Ctrl+B)
3. Запустить (Ctrl+R)
